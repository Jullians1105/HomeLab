# Metabase — Overview

Placeholder breve, listo para expandir cuando Metabase esté instalado (VLAN 30, oct 2026).

Metabase es la herramienta de BI (Business Intelligence) planeada para dar visibilidad de datos a los clientes de [[AIWorkspace (Consultoría)]] — dashboards y reportes conectados a las bases PostgreSQL de cada cliente, sin necesidad de que el cliente sepa SQL.

## Uso previsto

- Dashboards por cliente (facturación, inventario, operación según el rubro de cada uno)
- Insumo para reportes mensuales automáticos (ver idea en [[Ideas Futuras]])
