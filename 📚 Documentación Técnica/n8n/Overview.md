# n8n — Overview

Placeholder breve, listo para expandir cuando n8n esté instalado (VLAN 30, oct 2026).

n8n es la herramienta de automatización de workflows (low-code) usada como motor central de [[AIWorkspace (Consultoría)]]. Conecta APIs de clientes, tareas programadas y flujos de datos entre sistemas contables/administrativos sin escribir integraciones a medida para cada caso.
